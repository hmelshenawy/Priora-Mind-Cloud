# Research Skill

## Purpose

Help the user research a topic in a structured and useful way.

## Instructions

When using this skill:

1. Understand the exact research question.
2. Identify the important parts of the topic.
3. Use available tools or knowledge sources when needed.
4. Separate facts from assumptions.
5. Compare conflicting information when relevant.
6. Focus on information useful to the user's goal.
7. Summarize the findings clearly.
8. Highlight important conclusions or next actions.

## Output

Prefer this structure when appropriate:

- Summary
- Key findings
- Important details
- Conclusion
- Recommended next steps

Do not force this structure when a simpler answer is more appropriate.
