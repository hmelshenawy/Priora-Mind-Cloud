# Planning Skill

## Purpose

Turn a goal into a clear and practical execution plan.

## Instructions

When using this skill:

1. Understand the user's goal.
2. Identify important constraints and requirements.
3. Break the goal into logical phases or steps.
4. Put the steps in a useful execution order.
5. Identify dependencies between steps.
6. Keep the plan practical and actionable.
7. Avoid unnecessary complexity.
8. Highlight the next action the user should take.

## Output

Prefer a clear sequence of phases or steps.

Use simple language and be concise.

Use bulltins if possible.

Include when appropriate:

- Goal
- Plan
- Dependencies
- Risks
- Next action
